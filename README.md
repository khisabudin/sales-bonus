# Проектная работа "Пряники"
5 спринт, модуль JS

## Описание проекта
По собранным в датасете данным о продажах в магазине необходимо составить рейтинг продавцов по доходности и рассчитать бонусы для каждого продавца.

## Структура проекта
1. `data` - каталог с примерами данных
2. `src/main.js` - основной файл программы
3. `index.html` - файл для запуска программы

## Инструкция по запуску
Открыть любым способом файл `index.html` в браузере. В консоли DevTools (CTRL+Shift+I) будет выведен рейтинг продавцов и рассчитанные бонусы.

Чтобы изменить выбранный датасет, необходимо в файле `index.html` изменить ссылку в строке:
```html
<script src="data/dataset_1.js"></script>
```
Доступны 3 примера дата-сетов:
- `data/dataset_1.js`
- `data/dataset_2.js`
- `data/dataset_3.js`

# Задача
Реализовать подготовленные, но не заполненные функции опираясь на комментарии в коде.
Можно добавлять собственные функции и изменять код внутри функций, но не изменять имена функций и код запуска в `index.html`.

## Ключевые требования
- Программа написана на чистом JS без использования сторонних библиотек;
- Из основной функции анализа выделены функции для расчета прибыли и бонусов, что позволяет корректировать особенности расчетов без изменения основного кода;
- Используйте только чистые функции (функция получает все что ей необходимо для работы через аргументы), не обращающиеся к глобальным переменным и не имеющие побочных эффектов.

# Методика расчёта бонусов
Методика расчёта бонусов в проекте такая:
15% — для продавца, который принёс наибольшую прибыль.
10% — для продавцов, которые по прибыли находятся на втором и третьем месте.
5% — для всех остальных продавцов, кроме самого последнего.
0% — для продавца на последнем месте.

# Расчет выручки
Формула простая: доходы (выручка) минус расходы (себестоимость товаров). Чтобы посчитать выручку, нужно определить, сколько точно получено с продажи с учётом скидки и других факторов.
Это можно сделать так:
Перевести скидку из процентов в десятичное число: скидка / 100.
Посчитать полную стоимость, умножив цену продажи на количество.
Умножить полную стоимость на 1 - десятичная скидка, чтобы получить остаток суммы без скидки.
Рассчитать выручку можно разными способами. В будущем следует также учитывать в вычислениях налоги, региональные особенности, категории товаров. Поэтому вынесем расчёт выручки в отдельную функцию. Она будет учитывать данные о продаже конкретного товара и информацию о товаре из каталога, так как нам могут понадобиться данные о товаре, которых нет в чеке.

В функциях с более чем десятью строками эти шаги есть почти всегда:
Проверить переданные данные.
Проверить нужные для работы настройки/опции/зависимости.
Собрать промежуточные данные.
Выполнить основные действия.
Сформировать итоговый ответ.
